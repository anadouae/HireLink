\section*{Composants principaux}

\begin{itemize}
  \item \textbf{Frontend} : interface statique (Séance~1), consommation de \texttt{GET /api/v1/health} et \texttt{/meta}.
  \item \textbf{Backend} : Spring Boot (Web, Data JPA, Validation), exposition OpenAPI (\texttt{/swagger-ui.html}).
  \item \textbf{Persistance} : MySQL — entités \texttt{User}, \texttt{JobOffer}, \texttt{Application}.
  \item \textbf{Règle technique} : aucune API tierce payante ; appariement local de compétences (Jaccard).
\end{itemize}
