Sécurité & confiance

Les mêmes réflexes que les plateformes SaaS sérieuses : prouver qui vous êtes, protéger les accès, expliquer les décisions.

Authentification

JWT signé, BCrypt, OTP e-mail, Google Sign-In. Sessions sans cookie serveur (stateless).

Employeurs vérifiés

ICE + raison sociale + e-mail de domaine. Publication bloquée tant que non validé. Signalements d’offres (≥3 → suspension).

Données protégées

Isolation multi-tenant par organisation. Rôles RH / HM. En-têtes HSTS-ready, X-Frame-Options, no-store.

Décisions responsables

Machine d’états pipeline. Refus catalogue obligatoire. Timeline horodatée. SLA monitoré.

Engagements concrets (niveau SaaS)

  • Mots de passe hachés BCrypt — jamais stockés en clair
  • Jetons JWT à durée limitée + CORS strict par origine
  • Checklist RH avant chaque avance (identité, CV lu, SLA)
  • Catalogue de motifs de refus — pas de rejet silencieux
  • Score de fiabilité employeur (respect SLA × décisions explicites)
  • Import CV côté serveur — validation avant enregistrement
