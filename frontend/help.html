Questions fréquentes

Tout ce qu’il faut savoir pour utiliser HireLink comme un produit professionnel.

Comment créer un compte ?

Choisissez Inscription, indiquez si vous êtes candidat ou recruteur, puis validez votre email avec le code reçu. Vous pourrez définir un mot de passe ensuite.

Pourquoi un code par e-mail ?

C’est une connexion sans mot de passe : on vérifie que vous contrôlez bien l’adresse e-mail.

Comment les offres sont-elles personnalisées ?

À partir de votre formulaire profil (compétences, métiers, lieux, contrats). HireLink classe les offres pour coller à ce que vous cherchez.

Qu’est-ce que « statistiques de candidature avancées » (Premium) ?

Un tableau clair de combien vous avez postulé, où vous avancez, et vos meilleures compatibilités. Essentiel montre les compteurs de base ; Premium ajoute l’historique et les tendances.

Quels sont les tarifs ?

Candidat : Essentiel gratuit, Premium à 39 MAD/mois (alertes, profil mis en avant, stats).
Recruteur : Gratuit pour démarrer, Premium à 299 MAD/mois (équipe, offres en avant, reporting).
Pas de pénalités complexes — fluide et flexible.

Comment une entreprise est vérifiée ?

Comme LinkedIn : le recruteur renseigne la raison sociale et l’ICE. Si l’e-mail est professionnel et que l’ICE correspond au registre, le badge est attribué automatiquement. Sinon le dossier arrive dans l’espace admin (Entreprises → Vérifier). Sans badge, impossible de publier une offre.

Mot de passe oublié ?

Sur l’écran Connexion, utilisez « Mot de passe oublié » puis recevez un code par e-mail pour entrer.
